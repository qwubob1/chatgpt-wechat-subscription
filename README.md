## 微信支付订阅 ChatGPT Plus 的具体步骤

### 第一步：准备一个自己的 ChatGPT 账号

先在浏览器中登录你要开通 Plus 的 ChatGPT 账号。建议使用电脑浏览器完成首次操作，并确认账号邮箱无误。

### 第二步：选择 ChatGPT Plus

进入订阅页面后，选择 ChatGPT，再选择 Plus。页面通常会要求你选择单月订阅或长期订阅。

两种方式的区别比较直接：

- **单次订阅**：只开通一个月，到期后不继续续费。
- **长期订阅**：一次购买多个月，平台按月处理后续月份，通常月均价格更低。

长期方案需要特别注意自动续费和预存月份。帮助中心说明，多月套餐可能按月自动续费；如果在 ChatGPT 官方页面自行取消订阅，已经预付但尚未生效的月份可能受到影响。下单前应把周期、续费方式和生效规则看完。

### 第三步：提交账号会话信息

ChatGPT Plus 的开通流程需要用户在已经登录 ChatGPT 的同一浏览器中打开会话页面，并复制一段 JSON 信息，再粘贴回 WildAI 页面。

这一步最容易出错，常见原因包括：

- 浏览器没有登录 ChatGPT；
- 登录的是另一个账号；
- JSON 复制不完整；
- 复制时漏掉开头或结尾；
- 浏览器插件改写了复制内容；
- 把 ChatGPT 的 Session 信息粘贴到了 Pro 方案需要的 Cookie 输入框。

WildAI 的帮助文档区分了不同 ChatGPT 产品的凭证要求。Plus 主要使用登录会话信息；Pro 5x 还需要额外提交 Cookie。两种内容不能混用。

## 使用第三方订阅时，最需要注意什么？

### 1. Session 和 Cookie 都属于敏感信息

虽然平台帮助文档说明这些信息用于本次开通，但它们仍然属于账号授权凭证。不要把完整 JSON、Cookie 或登录信息发到群聊、论坛、私信或不明客服账号。

开通完成后，可以检查 ChatGPT 的登录设备和活跃会话，必要时重新登录、修改密码并开启双重验证。尤其是 Pro 方案需要提交 Cookie 时，操作前要确认浏览器扩展来源可靠，操作完成后不要继续保留不必要的导出文件。

### 2. 退款不是“付款后随时可退”

WildAI 的退款规则写明，已经完成履约且权益生效的订单，因选错套餐、误操作或购买后不想使用，原则上不支持退款。仍在处理中、尚未生效，或者多月套餐中存在未生效月份时，可以联系客服核实，但不代表一定自动退款。

所以付款前至少核对四项：

- ChatGPT 账号邮箱；
- Plus、Pro 5x 或 Pro 20x 档位；
- 订阅月数；
- 收银台最终金额。

### 3. Plus 不等于无限使用

官方 Plus 虽然提供更高额度和更多功能，但仍可能存在消息上限、模型上限或高峰期限制。OpenAI 也明确说明，使用限制会根据系统状况和具体模型变化。

如果你主要是普通聊天、写作、翻译和文件分析，Plus 已经覆盖大多数场景。若你每天长时间运行代码、持续进行深度研究或大量使用高级模型，再考虑 Pro 档位更合理。

### 4. ChatGPT Plus 不包含 API

ChatGPT Plus 和 OpenAI API 是两套独立计费体系。订阅 Plus 后，不能直接把 Plus 余额拿去调用 API；需要 API 的用户仍要在开发者平台单独充值。WildAI 的帮助中心也明确写出，目前提供的是 ChatGPT 会员订阅代充，不提供 OpenAI API 额度充值。
